# Assets

MachiVerseWorks のデザイン・ブランド・ドキュメント向けアセットを管理します。

## ディレクトリ

- `originals/`: 加工前の原本ファイルを保存する正本。画像・ロゴ等のマスターを置く。
- `brand/`: README・Repository紹介・ドキュメント等から参照する表示用ブランドアセット。

## 方針

- 原本は再圧縮、リサイズ、色調整などをせず、そのまま保存する。
- READMEやドキュメントからは原則として `brand/` の派生アセットを参照する。
- Web Clientで利用する場合は、用途に合った形式・サイズへ変換してWeb側のruntime asset領域へ配置する。
- アプリケーションのruntime assetと原本保管場所を分離し、原本が配布物へ無条件に含まれないようにする。
- 一般的な画像原本は通常のGitで管理する。Repository肥大化が問題になるサイズになった場合のみGit LFS等を再検討する。
