# Assets

MachiVerseWorks のデザイン・ブランド・ドキュメント向けアセットを管理します。

## ディレクトリ

- `originals/`: 加工前の原本ファイルを保存する正本。画像・ロゴ等のマスターを置く。

## 方針

- 原本は再圧縮、リサイズ、色調整などをせず、そのまま保存する。
- Web ClientやREADMEなどで利用する場合は、原本を直接変更せず用途に応じた派生ファイルを別途生成する。
- アプリケーションのruntime assetと原本保管場所を分離し、原本が配布物へ無条件に含まれないようにする。
- 一般的な画像原本は通常のGitで管理する。GitHubの通常ファイル上限やRepository肥大化が問題になるサイズになった場合のみGit LFS等を再検討する。
