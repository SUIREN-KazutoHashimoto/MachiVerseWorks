## 原本との関係

加工前の正本は [`../originals/`](../originals/) に保存します。

このディレクトリの画像は表示用途の派生アセットです。原本を修正する場合は、まず `originals/` のマスターを更新し、その後必要な派生アセットを更新します。

現在の2画像は原本と同一のバイト列を参照しており、再圧縮やリサイズは行っていません。
